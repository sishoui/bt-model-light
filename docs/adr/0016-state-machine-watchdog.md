# ADR-0016: 固件状态机 + 看门狗

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件

## 背景

固件运行态如何建模？灯控设备 7×24 通电，需考虑异常恢复。

## 决策

采用**显式状态机 + 独立看门狗任务**：

```
IDLE → CONNECTED → CONFIGURED → PLAYING → (PREVIEW / PAUSED)
```

- 命令触发迁移（见 ADR-0007 命令集）
- 非法迁移检测（如未配置时收到 APPLY → 回错误码 0x05）
- 独立看门狗任务：喂狗超时则复位固件
- 状态机让"未配置时收到 PLAY"等非法转移可检测、可回错误码

## 理由

- 显式状态机让非法转移可检测
- 看门狗是 7×24 设备必备
- 与 ADR-0007 命令集对应

## 影响

- 固件 `firmware/src/state_machine.c` 实现状态机
- 看门狗任务独立于协议处理
- `READ_STATUS`（cmd=0x04）返回当前状态

## 备选

- 无显式状态，事件驱动：非法转移不可检测
- 状态机但无看门狗：挂死后无法自恢复

# ADR-0009: 连接后协议版本协商

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序

## 背景

小程序与固件版本可能不一致（用户升级了小程序但固件未升级，或反之）。需明确版本兼容性策略。

## 决策

连接后小程序第一件事发 `GET_VERSION`（cmd=0x08），比对协议版本：

- 固件回包含 `protocol_version`（主.次）+ `firmware_version`
- 小程序校验 `protocol_version` 兼容（主次均匹配）
- 不兼容则提示用户升级小程序或固件，不继续下发命令
- 固件对未知命令回错误码 `0x02 不支持的命令`，**不崩溃**（向前兼容）

## 理由

- 避免协议不兼容时小程序发了固件不认识的命令
- 未知命令回错误码而非崩溃，保证固件稳定性
- 协议版本与固件版本分离，便于单独迭代

## 影响

- `protocol/versions.csv` 定义协议版本号
- 小程序连接流程：连接 → 协商版本 → 进入正常交互
- 代码生成包含版本常量

## 备选

- 不协商靠向后兼容：风险高，新命令旧固件不识别
- 仅启动时检测：连接后才发命令，太晚

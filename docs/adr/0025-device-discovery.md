# ADR-0025: 设备发现（设备名前缀过滤）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 小程序

## 背景

BLE 扫描/连接流程需明确：前缀过滤、显示所有、二维码绑定。

## 决策

采用 **设备名前缀过滤**：

- 小程序扫描所有 BLE 设备
- 按设备名前缀 `BTLight_` 过滤
- 列表展示信号强度（RSSI）
- 保存多台设备（见 ADR-0009 多设备）

## 理由

- 设备名前缀过滤最简单可靠，无需配网/绑定
- 二维码绑定留作多设备管理增强（v2）

## 影响

- 固件广播名 `BTLight_<id>`（id 为芯片 ID 或 MAC 后缀）
- 小程序 `wx.startBluetoothDevicesDiscovery` + 前缀过滤
- 保存设备列表到 Storage

## 备选

- 显示所有 BLE 设备：列表混乱
- 二维码绑定：需额外配网/绑定流程

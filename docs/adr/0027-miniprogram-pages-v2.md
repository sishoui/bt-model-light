# ADR-0027: 小程序页面结构（v2，supersedes ADR-0022）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 小程序, 文档
- Supersedes: ADR-0022

## 背景

ADR-0022 的 3 页结构（设备列表→设备详情→灯组编辑）在用户审阅参考布局后需要重构。用户希望首页即"设备详情页"，并以引脚卡片→灯组 Tab→步骤/图层为层级展开。底部需固定导航栏。

## 决策

### 页面层级

```
[底部导航: 设备 | 我的]
  ├─ 设备 Tab
  │   ├─ 首页 = 设备详情页 (current/last device)
  │   │    └─ 引脚卡片 → 引脚配置详情页
  │   │         └─ 灯组 Tab → 灯珠范围选择 → 步骤/图层 → 灯效+参数
  │   └─ 设备列表页 (左上标题点击进入，新增/切换)
  └─ 我的 Tab (设置、关于等)
```

### 首页（设备详情页）

- 左上角：设备名称 → 点击跳转设备列表页
- 设备卡片：设备图片、状态、整体开关、整体亮度滑块
- 引脚卡片列表：**只展示已配置的引脚**（未配置引脚不显示）
- 引脚卡片内容：引脚灯光开关、名称、图片、其他信息
- 点击引脚卡片 → 引脚配置详情页

### 引脚配置详情页

- 顶部：图片、名称、开关
- 灯组列表：**Tabs 标签页**
  - 默认 1 个 Tab
  - 右侧"+"按钮新增 Tab（每引脚 ≤5 灯组，对应 ≤5 Tab）
  - Tab 可删除/重命名
  - 点击 Tab 切换灯组

> 现状（2026-11-26）：灯组改**下拉框选择**（原生 `picker`），取代横向 Tab 条（提交 `2c37b59` 的长按弹配置窗一并调整）。灯组仍固定 5 个、无增删：下拉框显示当前组名称 + 灯珠区间，右侧「配置」按钮打开名称/灯珠范围弹窗；切换组走 `onGroupPick`（原 `onTapGroup`），配置弹窗走 `onOpenGroupConfig`（原 `onGroupLongPress`）。长按手势在原生 picker 内不可用，是入口由长按改为显式按钮的直接原因。本次改动未单独出 ADR。
- 灯组内容：
  - 灯珠范围选择：点选开头灯珠 + 结束灯珠，界面高亮 [start, end] 区间
  - 步骤/图层编辑器：默认 1 步骤、1 图层，可增删（每灯组 ≤5 步骤，每步骤 1~2 图层）
  - 图层 → 灯效下拉 + 参数表单联动（同页，不跳转）
  - 灯效 8 种扩展集（见 ADR-0017）

> 现状（2026-11-28）：步骤（UI 文案「阶段」）区改**竖向时间轴**。原「横向分段条（选中 + 长按拖排序）+ 泳道甘特时间轴 + 选中阶段气泡卡」三块合并为一条竖轴：左列是轴（每段起始秒 + 圆环节点 + 连线），右侧每段一张卡片就地展开全部字段，选中这一中间态随之取消（所有阶段同屏可见可改）。排序改用卡头 ↑↓：纵向长按拖动与页面滚动手势冲突，小程序侧无法阻止滚动抢占。`utils/chartHelpers.buildTimeline` 随之删除。本次改动未单独出 ADR。

> 现状（2026-11-28，第二次）：阶段卡片再重构为**圆环 + 刻度轴**范式。① 时长移出卡片，只由左轴圆点进入（环内显示秒数）；② 删除过渡/循环的 UI 入口（协议字段与数据模型保留，老配置原样透传）；③ 图层卡从两列改纵向一列，去掉点开的配置弹窗——每个可调参数是一枚 2rpx 细边进度环（环长 = 值占量程比例），点开在卡片下方展开刻度轴横向拖动改值，拖动中环同步走、松手才下发；④ 换灯效改原生 `picker`（`showActionSheet` 的 itemList 上限 6 项，灯效有 8 种）；⑤ 3D 灯效预览随弹窗一并移除，`utils/effectPreview.js` 删除。
> 实现注记：刻度轴的比例换算必须用浮点夹取（`clampRatio`），不能用 `configCodec.clampInt`——后者会 `Math.round`，把 0.4 的拖动比例取整成 0，环长与手柄会全部塌到两端。
> 图标注记：环内图标是一套 `bt-ico--p-*` 纯 CSS 伪元素图形（`currentColor`，28rpx 画框），参数名 → 图标名的映射在 `PARAM_ICONS`，新增 schema 参数时漏配会走兜底 `dot`。点击态只做描边高亮 + 图标转色，刻意不放大、不给内圈染底：进度弧加半透明圆盘会被读成「扇形」。

### 底部导航栏

- 固定 2 Tab：**设备**、**我的**
- "设备" Tab 默认显示首页
- "我的" Tab 放设置、关于、帮助等

### 设备列表页

- 由首页左上角设备名称点击进入
- 展示已保存设备列表 + "新增设备"入口（扫描/连接）
- 切换设备后返回首页

## 理由

- 首页即设备详情页，符合用户预期（打开小程序直接看到灯控设备）
- 引脚卡片列表只展示已配置引脚，界面清爽
- 灯组 Tab 符合"每引脚多灯组"的配置语义
- 同页灯效+参数联动减少跳转，适合小程序编辑场景
- 底部 2 Tab 足够，不做过多层级

## 影响

- 小程序 `pages/` 结构改为：
  - `pages/home/` 首页（设备详情）
  - `pages/device-list/` 设备列表
  - `pages/pin-detail/` 引脚配置详情
  - `pages/mine/` 我的
- 路由栈：home → pin-detail → (step/layer/effect 编辑在同页展开，不单独路由)
- 状态管理见 ADR-0023（页面级 data）
- 设备发现见 ADR-0025（扫描/连接流程不变）
- GLOSSARY 术语更新：首页=设备详情页

## 备选

- ADR-0022 的 3 页结构（列表→详情→编辑）：被本 ADR 取代
- 4 页含独立预览页：本 ADR 把灯效编辑收进引脚详情页的 Tab 内，不需要独立预览页
- 更多底部 Tab（如"灯效""设置"）：首版 2 Tab 足够

## 待细化（后续 grilling 轮次）

- 引脚详情页内"步骤/图层/灯效/参数"的具体布局（折叠面板 vs 滚动列表）
- 灯珠范围选择器的视觉交互（横条 + 高亮）
- 灯效参数表单的渲染方式（按效果 ID 查表渲染）
- "我的"页的具体内容（设置项、关于、帮助）

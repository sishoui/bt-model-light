# ADR-0018: 效果参数完全自定义（按效果 ID 查表）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序, 文档

## 背景

效果参数 schema 可选：共用+特有、完全自定义、仅颜色+亮度。需与 ADR-0017 的 8 种效果配套。

## 决策

采用**完全自定义参数集**，按效果 ID 查表解析：

- 共用参数：颜色（RGB）、亮度（0-255）、速度（1-100）、方向（正向/反向）
- 特有参数按效果 ID 定义，例如：
  - 呼吸：周期、波形
  - 闪烁：亮时长、灭时长
  - 跑马灯：灯珠数、间隔
  - 流星拖尾：拖尾长度、衰减系数
  - 双色渐变：第二颜色、渐变模式
  - 律动跳变：节奏模式、跳变步长

## 理由

- 完全自定义让每种效果有最合适的参数集，不被共用参数拖累
- 按效果 ID 查表解析，协议帧只需传 `effect_id + param_block`
- 代码生成从 `protocol/effects.csv` 派生参数表

## 影响

- `protocol/effects.csv` 定义效果 ID + 参数列表 + 类型 + 范围
- 协议帧图层结构：`[effect_id:1][param_block:...]`，param_block 长度由 effect_id 查表确定
- 小程序提供每效果的参数编辑器（表单）
- 固件实现每效果的参数解析与渲染

## 备选

- 共用+特有：被共用参数拖累，特有字段仍需查表
- 仅颜色+亮度：表达力不足，无法做律动/拖尾等效果

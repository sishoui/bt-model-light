# ADR-0026: 错误处理与用户提示

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 小程序, 固件, 文档

## 背景

BLE 失败/协议错误/固件拒绝时如何处理？统一错误码表、仅 Toast、静默失败。

## 决策

采用**统一错误码表 + 用户友好提示 + 本地日志**：

- 协议层错误码（见 ADR-0007）+ 小程序本地错误
- 小程序按错误码给用户友好提示（Toast/Modal）
- 关键错误记录到本地日志（便于排障）

## 理由

- 协议错误码表是 ADR-0007 命令集的一部分
- 用户友好提示提升体验
- 本地日志便于现场排障

## 影响

- `protocol/errors.csv` 定义错误码表，代码生成消费
- 小程序 `utils/errorHandler.js` 映射错误码 → 提示文案
- 关键错误写入 `wx.setStorage('error_log', ...)`

## 备选

- 仅 Toast：缺乏结构化排障信息
- 静默失败：用户无感知，体验差

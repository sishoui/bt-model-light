# ADR-0023: 小程序状态管理（页面级 data + 保存按钮）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 小程序

## 背景

小程序编辑中的配置如何管理？编辑即存、编辑态+保存、引入 mobx/redux。

## 决策

采用 **页面级 `data` + "保存"按钮**：

- 编辑态与已保存态分离，避免误操作立即写固件
- "保存"按钮同时写 Storage + 下发固件
- 页面级 `data` 够用，不引入状态库

## 理由

- 编辑态与已保存态分离，语义清晰
- 灯组配置是结构化数据，页面级 `data` 足够
- 不引入 mobx/redux，保持轻量

## 影响

- 灯组编辑页（现为"引脚配置详情页"的灯组 Tab 内）`data` 含：`ledRange`、`steps[]`、`layers[]`、`dirty` 标志
- "保存"按钮：写 `wx.setStorageSync('device_config_<id>', config)` + 下发 `WRITE_CONFIG` + `APPLY`
- 编辑中切换页面提示"未保存"
- 跨页面共享状态（如首页整体开关、当前选中设备）用 `getApp()` 全局或 Storage，见 ADR-0027

## 备选

- 编辑即存 Storage：误操作立即写固件，风险
- 引入状态库：对单页编辑过度

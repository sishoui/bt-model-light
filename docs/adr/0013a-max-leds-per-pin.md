# ADR-0013a: 每引脚灯珠数上限 100

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件

## 背景

ESP32-C3-FH4 无 PSRAM，RAM 有限。每引脚灯珠数上限决定帧缓冲大小。

## 决策

每引脚 **≤100 颗**，8 引脚共 ≤800 颗。

- 每引脚帧缓冲：100 × 3 = 300 字节
- 8 引脚帧缓冲：8 × 300 = 2400 字节
- 双缓冲（当前 + 下一帧）：4800 字节
- 余量充足（ESP32-C3 有 ~400KB SRAM）

## 理由

- 100 颗/引脚覆盖大多数灯带长度（2.5m/5m 常见配置）
- 双缓冲 4.8KB 在 RAM 余量内
- 配置单帧 ~1.5KB（800 颗灯组配置），BLE 分段重组可控

## 影响

- 协议 `GET_PIN_CAPS` 命令返回每引脚实际灯珠数
- 小程序配置校验：灯珠区间 `[start, end]` 满足 `0 ≤ start ≤ end < 100`
- 固件缓冲预分配 100 颗/引脚

## 备选

- 60/引脚：偏保守
- 不限制：ESP32-C3 无 PSRAM，无法承载 8 路大缓冲

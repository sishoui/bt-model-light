# ADR-0015: 出厂默认灯效 + 长按 BOOT 恢复

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件

## 背景

设备首次上电或 spiffs 配置损坏时需明确行为。用户期望开箱即亮，确认硬件正常。

## 决策

- 固件检测 spiffs 配置不存在/校验失败 → 进入 `IDLE` 并广播"未配置"状态，等待小程序下发
- 但同时**内置一份出厂默认灯效**（如呼吸彩光），首次上电自动播放（用户通电就能看到灯亮，确认硬件正常）
- 长按 BOOT 键 5s → 清空 spiffs 配置 + 恢复出厂默认

## 理由

- 出厂默认让设备开箱即用
- 长按 BOOT 恢复出厂是现场排障刚需
- spiffs 配置损坏时 fallback 到出厂默认，避免设备变砖

## 影响

- 固件内置出厂默认配置常量（呼吸彩光，8 引脚全覆盖）
- BOOT 键长按检测（GPIO9 是 ESP32-C3 的 BOOT 键）
- 状态机 `IDLE` 状态在出厂默认播放时进入 `PLAYING`（见 ADR-0016）

## 备选

- 仅"未配置"状态不播放：开箱不亮，用户体验差
- 无恢复出厂：排障困难

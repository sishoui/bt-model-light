# ADR-0007: 命令集（完整集）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序, 文档

## 背景

协议层需要定义命令集。最小集不够用（无法预览单步、恢复默认、读版本），全量集对灯控过重。

## 决策

采用**完整集**命令：

| cmd | 名称 | 方向 | 说明 |
|---|---|---|---|
| 0x01 | 写配置 (WRITE_CONFIG) | 小程序→固件 | 单条下发整台配置（~1.5KB） |
| 0x02 | 读配置 (READ_CONFIG) | 小程序→固件 | 读回当前配置 |
| 0x03 | 应用 (APPLY) | 小程序→固件 | 下发到灯珠，开始播放 |
| 0x04 | 读状态 (READ_STATUS) | 小程序→固件 | 读状态机当前状态 |
| 0x05 | 单步触发 (TRIGGER_STEP) | 小程序→固件 | 只播第 N 步（灯组索引+步骤索引） |
| 0x06 | 停止 (STOP) | 小程序→固件 | 停止播放，保持当前亮灯 |
| 0x07 | 恢复默认 (RESET_DEFAULT) | 小程序→固件 | 恢复出厂默认灯效 |
| 0x08 | 读版本 (GET_VERSION) | 小程序→固件 | 读协议版本 + 固件版本 |
| 0x09 | 读引脚能力 (GET_PIN_CAPS) | 小程序→固件 | 读每引脚灯珠数 |
| 0x0A | 设整机亮度 (SET_BRIGHTNESS) | 小程序→固件 | 所有引脚统一缩放（0-255，255 = 不缩放），输出级生效（ADR-0031） |
| 0x0B | 设整机开关 (SET_POWER) | 小程序→固件 | 0 = 关（输出全黑，不改引脚状态）/ 1 = 开（ADR-0032） |
| 0x81 | 状态回传 (STATUS_NOTIFY) | 固件→小程序 | notify 通道，回传状态/错误/进度 |
| 0xF0 | OTA (预留给 v2) | 双向 | 命令码预留，流程延后 |

> 0x0A / 0x0B 由 ADR-0031 / ADR-0032 增补，负载定义见 `protocol/frame-spec.md`；命令码表以 `protocol/commands.csv` 为准（本表为决策时的快照）。

## 理由

- 单步触发对"预览第 N 步效果"有用，否则要编辑整个配置才能预览
- 恢复默认、读版本是现场排障刚需
- 读引脚能力让小程序自动适配不同灯珠数配置
- OTA 命令码预留但不实现（见 ADR-0008）

## 影响

- `protocol/commands.csv` 定义命令码表，代码生成消费
- 未知命令固件回错误码 `0x02 不支持的命令`，不崩溃
- 连接后小程序第一件事发 `GET_VERSION`（见 ADR-0009）

## 错误码表

| 错误码 | 含义 |
|---|---|
| 0x01 | 校验和错误 |
| 0x02 | 不支持的命令 |
| 0x03 | 配置超限（灯珠/灯组/步骤/图层数超限） |
| 0x04 | 参数非法（长度/范围越界） |
| 0x05 | 状态非法（如未配置时收到 APPLY） |
| 0x06 | 缓冲区不足 |
| 0x07 | 内部错误 |
| 0x08 | 协议版本不兼容 |

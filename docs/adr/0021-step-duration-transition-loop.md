# ADR-0021: 步骤时长/过渡/循环模式

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序, 文档

## 背景

每个步骤的持续时间、过渡、循环模式需明确。候选：固定时长、时长+过渡、时长+过渡+循环模式。

## 决策

采用**时长可配 + 可选过渡 + 循环模式**：

- 每步骤时长：1~60 秒可配
- 过渡：淡入淡出 / 平滑切换 / 无（默认无）
- 循环模式（整个灯组）：单次播放 / 循环 / 往复（正放+倒放）

## 理由

- 时长可配覆盖"快速闪烁"到"长时间渐变"的场景
- 过渡让步骤切换不生硬
- 循环/往复是"灯效图层"语义的完整表达

## 影响

- 协议帧步骤结构：`[duration:2][transition:1][loop_mode:1][layer_count:1][layers...]`
- 固件渲染循环按步骤时长定时切换
- 小程序灯组编辑页提供时长/过渡/循环模式控件

## 备选

- 固定时长：灵活性不足
- 无过渡：步骤切换生硬
- 无循环模式：无法做"重复播放"场景

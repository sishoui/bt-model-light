# ADR-0013: 8 引脚顺序刷新 WS2812B

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件

## 背景

硬件描述"8 个引脚分时复用"，但 ESP32-C3 + WS2812B 的"分时复用"含义需明确。候选：顺序刷新、硬件 mux、PWM 分时。

## 决策

8 引脚**顺序刷新**：每引脚挂独立 WS2812B 灯带，固件循环更新各引脚。WS2812B 自带锁存，顺序刷新天然成立。

- 每引脚独立灯珠数（≤100，见 ADR-0013a）
- 固件循环：引脚0 刷新 → 引脚1 刷新 → ... → 引脚7 刷新 → 重复
- 每引脚独立配置（灯珠区间、灯组、步骤、图层）

## 理由

- WS2812B 自锁存，顺序刷新无需硬件 mux
- 每引脚独立灯珠数与范围，便于配置
- 8 路 WS2812B 用 ESP32-C3 RMT 外设驱动，时序稳定

## 影响

- 固件维护 8 个引脚的灯带缓冲（每引脚 ≤100 颗 × 3 字节 RGB）
- 帧缓冲总量 ≤ 8 × 100 × 3 = 2400 字节
- 顺序刷新周期与灯效帧率相关（见步骤时长/过渡）

## 备选

- 硬件 mux：增加硬件复杂度
- PWM 分时：适合单色 LED，WS2812B 是数字协议，PWM 不适用

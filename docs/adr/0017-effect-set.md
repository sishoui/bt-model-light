# ADR-0017: 灯效 8 种扩展集

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序, 文档

## 背景

灯效图层的效果集需明确。候选：基础集（5 种）、扩展集（8 种）、仅纯色、自定义关键帧。

## 决策

采用**8 种扩展集**：

| ID | 效果 | 说明 |
|---|---|---|
| 0x01 | 常亮 (SOLID) | 纯色常亮 |
| 0x02 | 呼吸 (BREATH) | 亮度正弦变化 |
| 0x03 | 闪烁 (BLINK) | 亮灭切换 |
| 0x04 | 跑马灯 (MARQUEE) | 逐灯珠点亮 |
| 0x05 | 彩虹渐变 (RAINBOW) | 色相渐变 |
| 0x06 | 流星拖尾 (METEOR) | 亮头+渐暗尾 |
| 0x07 | 双色渐变 (DUAL_GRADIENT) | 两色间渐变 |
| 0x08 | 律动跳变 (RHYTHM) | 按节奏跳变 |

- 共用参数：颜色、亮度、速度、方向
- 特有参数按效果 ID 查表解析（见 ADR-0018）

## 理由

- 覆盖"背景层用常亮/渐变、动效层用呼吸/闪烁/跑马灯"的典型组合
- 参数化（颜色、速度、亮度、方向）即可衍生大量变体
- 扩展集与关键帧留作 v2

## 影响

- `protocol/effects.csv` 定义效果 ID 表，代码生成消费
- 固件实现 8 种效果渲染函数
- 小程序提供 8 种效果的参数编辑器

## 备选

- 基础集 5 种：覆盖不足
- 仅纯色：太简化
- 自定义关键帧：小程序侧工作量最大，v2

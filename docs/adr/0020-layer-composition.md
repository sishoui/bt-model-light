# ADR-0020: 图层合成规则（动效层亮灯优先）

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序, 文档

## 背景

双图层时如何合成显示？候选：RGB 非黑判定、独立点亮掩码、alpha 通道。

## 决策

采用 **RGB 非黑判定**：动效层按帧算 RGB，该灯珠 RGB ≠ 000（非黑）即亮灯 → 取动效层 RGB；否则取背景层 RGB。

## 理由

- WS2812B 无 alpha 通道，"亮灯"本质是"该灯珠颜色非黑"
- 与"动效层亮灯优先"语义直接对应
- 掩码方案需额外传输掩码数据，冗余
- alpha 通道对 WS2812B 不适用

## 影响

- 固件渲染循环：对每灯珠先算动效层 RGB，非黑则用动效层，否则用背景层
- 单图层：直接显示该图层
- 合成在固件侧完成，小程序只配参数

## 备选

- 独立点亮掩码：传输冗余
- alpha 通道：WS2812B 不支持

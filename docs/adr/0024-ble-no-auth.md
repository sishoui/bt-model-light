# ADR-0024: BLE 无鉴权

- 状态: 已接受
- 日期: 2026-11-23
- 标签: 固件, 小程序

## 背景

BLE 控制是否需配对/鉴权？无鉴权、BLE 配对、应用层 token。

## 决策

采用**无鉴权**：任何能 BLE 连上的设备都能控制灯。

## 理由

- 灯控设备通常在家里，物理可达性就是安全边界
- BLE 配对会让"朋友来家里想控制灯"变复杂
- 应用层 token 对 BLE 灯控过重
- OTA 时再考虑签名校验（v2）

## 影响

- BLE 不做配对加密
- 固件接受任何连接
- 小程序连接即用，无登录/绑定

## 备选

- BLE 配对：友机访问复杂
- 应用层 token：对灯控过重
